# Scorciatoie e command palette

Su Windows e Linux usa **Ctrl** al posto di **⌘**. Premi **?** in qualsiasi pagina per vedere l'elenco completo dentro l'app.

## Ovunque

| Scorciatoia | Azione |
|---|---|
| **⌘K** oppure **⇧⌘P** | Apre/chiude la command palette (funziona anche mentre scrivi) |
| **?** | Elenco delle scorciatoie |
| **/** | Mette il cursore nel campo di ricerca della pagina (se non c'è, apre la palette) |
| **⌘[** / **⌘]** | Indietro / avanti (anche con i tasti laterali del mouse; Alt+←/→ su Windows e Linux) |
| **⌘1** … **⌘5** | Dashboard, Appunti, Calendario, Aule libere, Da fare |
| **⌘,** | Impostazioni |
| **⇧⌘F** | Cerca nelle lezioni |
| **⌘N** | Nuovo appunto (nel corso aperto, se ce n'è uno) |
| **⇧⌘S** | Sincronizza tutti i corsi |
| **⇧⌘T** | Pomodoro: avvia / pausa |
| **⇧⌘L** | Alterna chiaro / scuro |
| **⌘J** | Mostra o nasconde il registro attività |
| **⌘\\** | Mostra o nasconde la barra laterale (da nascosta si riapre passando col mouse sul bordo sinistro) |
| **⌃Tab** / **⌃⇧Tab** | Scheda successiva / precedente nella pagina del corso |
| **Esc** | Chiude finestre e menu |

### Sequenze «g»

Fuori dai campi di testo premi **g** e poi una lettera (stile Gmail/Linear):

| Sequenza | Va a |
|---|---|
| **g d** | Dashboard |
| **g n** | Appunti |
| **g c** | Calendario |
| **g a** | Aule libere |
| **g t** | Da fare |
| **g s** | Cerca |
| **g i** | Impostazioni |
| **g 1** … **g 9** | Il corso in quella posizione della barra laterale |

## Command palette

Scrivi per filtrare: la ricerca è fuzzy (bastano le iniziali, es. «nam» → *Nuovo appunto Markdown*) e le lettere trovate sono evidenziate. A palette vuota trovi i **comandi recenti**, quelli **della pagina in cui sei** e le sezioni principali; i comandi che usi più spesso salgono in classifica.

| Tasto | Azione |
|---|---|
| **↑ ↓**, **Tab**, **⌃N / ⌃P** | Muoversi tra i risultati |
| **PagSu / PagGiù** | Salta di 8 risultati |
| **↵** | Esegui |
| **⌘↵** | Chiedi all'AI il testo scritto |
| **Esc** | Svuota il campo; se è già vuoto chiude |

Prefissi per restringere la ricerca:

| Prefisso | Mostra solo |
|---|---|
| **>** | Comandi (azioni, vista, pomodoro, impostazioni) |
| **@** | Corsi (panoramica, lezioni, materiale) |
| **#** | Appunti |
| **?** | Domanda all'AI (↵ chiede subito) |

Gruppi di comandi: *In questa pagina* (es. schede del corso, play/pausa, trascrivi, compila), *Vai a*, *Corsi*, *Appunti*, *Azioni*, *Pomodoro*, *Vista*, *Impostazioni*. Con 3 o più caratteri compaiono anche «Cerca ovunque», «Chiedi all'AI» e i primi risultati della ricerca semantica nelle lezioni.

## Elenco delle lezioni

| Tasto | Azione |
|---|---|
| **j** / **k** | Lezione successiva / precedente (anche **↓ ↑** quando una lezione è selezionata) |
| **↵** | Apri la lezione selezionata |
| **/** | Cerca nelle lezioni (**Esc** svuota la ricerca) |

Tornando indietro da una lezione, l'elenco riparte dalla lezione che avevi aperto.

## Pagina della lezione (player)

| Tasto | Azione |
|---|---|
| **[** / **]** | Lezione precedente / successiva |
| **Spazio** | Play / pausa |
| **←** / **→** | Indietro / avanti di 10 s |
| **F** | Schermo intero |
| **>** oppure **.** | Più veloce (+0.25×) |
| **<** oppure **,** | Più lento (−0.25×) |
| clic su una riga della trascrizione | Salta a quel punto |

Flashcard (con il mazzo selezionato): **Spazio** per girare la carta, **← / →** per la carta precedente o successiva.

Chat della lezione e pannello AI degli appunti: **↵** invia, **⇧↵** va a capo.

## Appunti

| Scorciatoia | Azione |
|---|---|
| **⌘N** | Nuovo appunto |
| **⌘⇧E** | Mostra o nasconde l'elenco dei file |
| **⌘S** | Salva (gli appunti si salvano comunque da soli) |
| **⌘↵** | Compila (LaTeX e Typst) |
| **Invio** nel titolo | Rinomina l'appunto |

## Ricerca

| Scorciatoia | Azione |
|---|---|
| **↵** | Cerca |
| **⌘↵** | Chiedi all'AI (risposta con citazioni) |
