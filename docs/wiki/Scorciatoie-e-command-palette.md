# Scorciatoie e command palette

Su Windows e Linux usa **Ctrl** al posto di **⌘**.

## Ovunque

| Scorciatoia | Azione |
|---|---|
| **⇧⌘P** oppure **⌘K** | Apre la command palette |
| **⌘\\** | Mostra o nasconde la barra laterale (da nascosta si riapre passando col mouse sul bordo sinistro) |
| **Esc** | Chiude finestre e menu |

## Command palette

Scrivi per filtrare. **↑ ↓** per muoverti, **↵** per eseguire, **⌘↵** per chiedere all'AI il testo scritto.

| Gruppo | Comandi |
|---|---|
| Vai a | Dashboard, Cerca, Appunti, Calendario, Aule libere, Da fare, Community, Impostazioni; per ogni corso Panoramica, Lezioni e Materiale |
| Appunti | Nuovo appunto Markdown / LaTeX / Typst; apri un appunto esistente scrivendone il nome |
| Aspetto | Tema Normale / Developer; Chiaro / Scuro / Come il sistema; Font JetBrains Mono / Sistema; Mostra o nascondi barra laterale |
| Azioni | Sincronizza tutti i corsi; Sincronizza *corso*; Rigenera la descrizione di *corso*; Applica le funzioni AI alle lezioni già trascritte; Aggiorna indice di ricerca; Aggiorna orario delle lezioni |
| Pomodoro | Avvia o pausa; Azzera |
| Impostazioni | Salta direttamente a Trascrizione, AI, Integrazioni, Sincronizzazione cloud, Appunti, Pomodoro, Aspetto |
| Cerca | Con 3 o più caratteri: «Cerca ovunque», «Chiedi all'AI» e i primi risultati della ricerca semantica |

## Pagina della lezione (player)

| Tasto | Azione |
|---|---|
| **Spazio** | Play / pausa |
| **←** / **→** | Indietro / avanti di 10 s |
| **F** | Schermo intero |
| **>** oppure **.** | Più veloce (+0.25×) |
| **<** oppure **,** | Più lento (−0.25×) |
| clic su una riga della trascrizione | Salta a quel punto |

Flashcard (con il mazzo selezionato): **Spazio** per girare la carta, **← / →** per la carta precedente o successiva.

Chat della lezione e pannello AI degli appunti: **↵** invia, **⇧↵** va a capo.

## Appunti

| Scorciatoia | Azione |
|---|---|
| **⌘N** | Nuovo appunto |
| **⌘⇧E** | Mostra o nasconde l'elenco dei file |
| **⌘S** | Salva (gli appunti si salvano comunque da soli) |
| **⌘↵** | Compila (LaTeX e Typst) |
| **Invio** nel titolo | Rinomina l'appunto |

## Ricerca

| Scorciatoia | Azione |
|---|---|
| **↵** | Cerca |
| **⌘↵** | Chiedi all'AI (risposta con citazioni) |
